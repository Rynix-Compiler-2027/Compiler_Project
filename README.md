# Compiler_Project
## Rynix Compiler

A Compiler Theory project for the **Rynix Programming Language**, developed using C# and Windows Forms.

## Milestones

### Milestone 1 – Scanner
- Regular Expressions and DFAs for token classes.
- Scanner implementation.
- Lexeme-to-Token table.
- Lexical error detection.

### Milestone 2 – Parser
- CFG construction (terminals and production rules).
- Elimination of left recursion and left factoring.
- Recursive Descent Parser implementation.
- Parse tree generation.
- Syntax error detection.

## Features
- Source code editor.
- Lexeme-to-Token table.
- Combined lexical and syntax error list.
- Parse tree visualization.

## Technologies
C# · Windows Forms · Visual Studio

## Project Structure
- `Milestone 1` – Scanner documentation and deliverables.
- `Milestone 2` – CFG documentation and parser.
- `Source Code` – Compiler implementation.
